## 🌸 Aura Beauty Salon Telegram Bot
Проект создан в учебных целях в рамках практики по разработке Telegram-ботов.

Telegram-бот для салона красоты **Aura**, который предоставляет информацию об услугах и прайс-лист.

<img src=screanbot.png>
### 📋 Возможности

- 📋 Интерактивное меню с кнопками
- 💰 Прайс-лист на услуги: Стрижка, Маникюр, Макияж, Педикюр
- 🗄 Хранение данных об услугах в SQLite базе данных
- 🧱 Модульная архитектура (разделены работа с БД, бизнес-логика и обработчики Telegram)

### 🛠 Структура проекта

- `db.py` — работа с SQLite базой данных (подключение, инициализация таблиц, получение услуг)
- `service.py` — бизнес-логика (справочник услуг, генерация текстового прайса)
- `bot.py` — обработчики сообщений Telegram и настройка приложения бота
- `run_bot.py` — скрипт запуска бота с интерактивным запросом токена
- `test.py` — тестовый скрипт для проверки работоспособности базы данных и сервисов

### ⚙️ Установка и настройка

1. Клонируйте репозиторий или скачайте файлы проекта:
   ```bash
   git clone <repository-url>
   cd practice/21
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install python-telegram-bot
   ```

3. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather):
   - Отправьте команду `/newbot`
   - Придумайте имя и юзернейм для бота (юзернейм должен заканчиваться на `bot`)
   - Получите токен бота (вид: `123456789:AAFw...`)

### 🚀 Запуск бота

#### Вариант 1: Интерактивный запуск (Рекомендуемый)
Запустите бота через скрипт `run_bot.py`, который запросит токен в консоли:
```bash
python run_bot.py
```

#### Вариант 2: Через переменную окружения
Задайте токен через переменную окружения `BOT_TOKEN` и запустите `bot.py`:

**Windows (Command Prompt):**
```cmd
set BOT_TOKEN=ваш_токен_бота
python bot.py
```

**Linux / macOS:**
```bash
export BOT_TOKEN=ваш_токен_бота
python bot.py
```

### 🧪 Тестирование

Для проверки работы базы данных и бизнес-логики запустите тесты:
```bash
python test.py
```
